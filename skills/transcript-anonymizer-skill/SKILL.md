# 리서치 데이터 익명화 **검사** 스킬

## 이 스킬이 하는 일과 하지 않는 일

**2026-08-27 사용자 확정 — 익명화는 리서처가 반드시 직접 진행합니다. 이 스킬은 치환하지 않습니다.**

| | 리서처 | 이 스킬 |
|---|---|---|
| 실명·연락처를 실제로 치환·삭제 | **직접 수행** | **하지 않음** |
| 어떤 이름을 어떤 PID로 매핑할지 결정 | **결정** | 제안하지 않음 |
| 익명화가 끝났다고 판단 | **판단** | 판단하지 않음 |
| 익명화 결과에서 빠진 것을 찾아 위치를 알려주기 | 요청 | **수행** |

팀 공통 규칙(무엇을 어떻게 익명화하는지, 자주 놓치는 자리, 체크리스트)은 [`익명화_공통규칙.md`](../../../익명화_공통규칙.md)에 있습니다. **이 스킬의 판정 기준은 그 문서이며, 규칙을 여기에 복제하지 않습니다.**

## 절대 금지

1. **치환·수정하지 않습니다.** 원본이든 사본이든 파일을 쓰지 않습니다. 검사는 읽기 전용입니다.
2. **탐지한 값을 저장하지 않습니다.** 실명·연락처·주소 등 실제 값을 파일에 남기지 않으며, **마스킹한 형태(`김***님`)도 저장하지 않습니다** — 첫 글자와 길이만으로도 좁혀집니다. 저장·출력하는 것은 **위치(파일·시트·행·열)와 카테고리와 건수**뿐입니다.
3. **검사 결과를 repo에 커밋하지 않습니다.** 화면에서 확인하고 끝냅니다.
4. **값을 요약·재기술·예시로 다시 쓰지 않습니다.** 대화에서도 값을 옮겨 적지 않고 위치로만 지목합니다.
5. **native repo를 수정하지 않습니다**(AGENTS.md §0).

> 저장·커밋 금지는 이 repo 안에서 보장되는 범위입니다. 모델 학습 여부는 사용하는 AI 서비스의 설정·계약 사안이므로, 참여자 데이터를 외부 서비스에 올리는 것 자체는 사전 협의가 필요합니다(조직 지침).

## 입력

- 리서처가 **익명화를 마쳤다고 판단한** 파일: `.docx` · `.xlsx` / `.xlsm` · `.csv` · `.txt` / `.md`
- 익명화 전 원본을 검사 대상으로 받았다면, 먼저 그 사실을 알리고 [`익명화_공통규칙.md`](../../../익명화_공통규칙.md)를 안내합니다. 검사는 익명화 **이후** 단계입니다.

## 실행

```bash
python .agents/skills/transcript-anonymizer-skill/scripts/scan_pii.py <파일...>
```

- 기본 출력은 **위치·카테고리·건수뿐**입니다. 값이 나오지 않습니다.
- `--locate` 를 붙이면 행 단위 위치까지 나옵니다(값은 여전히 없음). 리서처가 그 행을 열어 직접 고칩니다.
- 파일로 저장하려면 `--save-counts <경로>` 를 씁니다. **건수 집계만** 저장되며 값·마스킹 샘플은 포함되지 않습니다.
- 스크립트는 값을 출력하는 모드를 제공하지 않습니다.

## 보고 형식

리서처에게 아래를 알립니다.

1. **카테고리별 잔존 건수** — 이름+호칭 / 진행자 자기소개 / 학교 / 회사 / 전화 / 이메일 / 주민번호 / 계좌·카드 / 주소
2. **위치** — 파일명, 시트명, 행 번호 (열이 특정되면 열까지)
3. **보존 확인** — 서비스명·기업명이 몇 건 보존됐는지 (지워지지 않았는지 확인용)
4. **오탐으로 제외한 건수** — `선생님`·`고객님` 류 직함/일반명사, 제도명, 날짜. 왜 제외했는지 카테고리로만
5. **이미 익명화되어 손대지 않아도 되는 화자 라벨의 개수** (값 아님)
6. **검사 한계** — 호칭 없는 맨 이름·별명은 이 방식으로 탐지되지 않습니다. "0건"이 "PII 없음"을 뜻하지 않는다고 명시합니다

값을 알려달라는 요청을 받으면, 값 대신 **위치를 좁혀** 알려주고(파일·시트·행) 그 행을 열어 확인하도록 안내합니다.

## 검사 범위 (파일 구조별)

- **docx**: 본문 + 머리말·꼬리말·주석·각주·메모까지 읽습니다. Word SDT(content control) 구조는 `paragraph.text`로 안 읽히므로 raw XML의 `<w:t>`를 긁습니다(AGENTS.md §4).
- **xlsx**: 전 시트의 모든 셀. 화자가 별도 컬럼인 표형 구조가 다수입니다 — 실측 102건 중 라인 기반(`화자: 발화`)으로 화자가 잡힌 파일은 10건뿐이고 나머지 92건이 표형이었습니다.
- **미지원**: `.pdf`, `.xls`(xlrd 미설치). 이 경우 검사하지 못했다고 분명히 말합니다 — 조용히 건너뛰지 않습니다.

## 실측 기준선 (2026-08-27, native 전사본 102건 전수)

검사 결과를 해석할 때 참고합니다. 상세는 `validation_runs/transcript-anonymizer-skill/2026-08-27_multi-project/`.

| 항목 | 값 |
|---|---|
| 스캔 파일 | 102 (읽기 실패 0) |
| PII 후보 잔존 파일 | **63** |
| 잔존 건수 (오탐 제거 후) | 이름+호칭 273 · 진행자 자기소개 11 · 회사 7 · 휴대전화 6 · 학교 2 · 계좌 1 · 일반전화 1 |
| 오탐으로 제외 | 일반명사 393 (`선생님` 단독 **346**) · 제도명 100 · 날짜 81 |
| 보존 확인 | 서비스명 매치 25건 |

이름 후보는 필터 전 631건 → 후 273건, **초기 탐지의 57%가 오탐**이었습니다. 그래서 검사 결과를 그대로 일괄 치환에 쓰면 원문이 훼손됩니다 — 반드시 사람이 위치를 열어 판단해야 합니다.

## 이 스킬로 쓰기 좋은 요청

- 이 전사본 익명화했는데 빠진 게 있는지 봐줘
- 이 폴더 파일들에 실명이나 연락처가 남아 있는지 검사해줘
- 서비스명이 실수로 지워지지 않았는지 확인해줘
- 익명화 체크리스트 어디까지 됐는지 알려줘
