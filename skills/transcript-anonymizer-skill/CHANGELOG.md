## 기록 규칙

- 새 항목은 파일 맨 위에 추가한다(최신이 위).
- 각 항목: `## YYYY-MM-DD — 한 줄 요약` + `- 계기:` + `- 변경:` + `- 검증:` + `- 남은 일:`

  - **`익명화_공통규칙.md` 신설 (repo 루트)** — 팀 공통 SSOT. 역할 경계표 · 익명화 대상 7종 · 자주 놓치는 자리(파일 첫 3행 메타·문서 속성·머리말/꼬리말/주석·시트 탭명·업체 export 질문 컬럼) · 보존 목록(서비스명 100% 보존) · PID 규칙 · 이미 익명화된 라벨 · 일괄치환 오탐 주의 · 파일 저장 규칙 · 15항목 체크리스트. **판정 기준은 이 문서이며 스킬에 규칙을 복제하지 않는다.**

  - **SKILL.md 규칙 0 신설 — 이미 익명화된 화자 라벨 재치환 금지.** 기존 규칙 1은 `P7`만 예외로 인식해서, `26.GP.UXQ`의 `S1`~`S9` 체계를 실명처럼 취급하고 `P001`~`P008`로 바꾸려 했다. 세션 번호 대응과 하위 산출물 연결이 끊기는 손실이다. (결함 A1)
  - **SKILL.md 규칙 0-1 신설 — PID 배정 순서.** 세션·파일·일시 순으로 배정하고 **발화량 정렬 금지**(검증에서 S8이 발화 272회로 P001이 됐다). 차수를 넘어 연속 부여(`24.ST.GBI` 2차가 `P19`부터). 표기 형식은 프로젝트 기존 표기 우선 — `[P001]`(이 스킬) / `P001`(#44) / `P19`(실제) 삼중 불일치를 명시. (A1·A6)
